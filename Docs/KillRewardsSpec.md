# 적 처치 보상과 획득 표시 (2026-11-18)

최신 사용자 확정으로 일반 적은 처치당 일반재화 2, 빠른 적은 1를 지급한다. 이전에 적용한 일반10/빠른5를 최신 사용자 정정값으로 대체한다. 보스 보상은 변경하지 않는다.

- 실제 체력이 0이 되어 Wave의 생존 목록에서 제거되는 순간 한 번 지급한다. 사망 연출 종료나 풀 반환에서는 추가 지급하지 않는다.
- 탈출은 처치 보상을 지급하지 않는다. 패배·승리로 끝난 뒤에는 추가 지급하지 않는다.
- StageCurrency에 바로 합산하므로 상단 잔액과 기존 비용 부족/던지기 가능 여부도 갱신된다. 웨이브 완료 보상은 별도로 유지한다.
- 표시 내용은 배경 없이 작은 코인 아이콘과 `+2` 또는 `+1`다. 처치 위치 위에서 약 0.8초 동안 24 UI픽셀 위로 떠오르며 후반에 투명해진다. 표시 후 적이 움직이거나 재사용되어도 따라가지 않는다.
- 표시 금액은 실제 지갑에 추가된 금액이다. 정수 상한에 도달해 수입이 제한될 때에도 실제 수입과 일치한다.
- 금액 표시는 클릭을 받지 않는다. 게임 일시정지 시 함께 멈추며, 최종 승리·패배 시 정리한다.
- Unity Canvas의 Enemy Kill Rewards 컴포넌트에서 일반 보상·빠른 적 보상·표시 시간을 조정할 수 있다. 코인과 숫자는 기존 UI 에셋을 사용한다.

실제 Play Mode 검사: 일반2/빠른1, 보스 무변경, 중복 피해와 사망 콜백의 중복 지급 방지, 탈출 무보상, 재사용한 적의 1회 지급, 표시 소멸, 기존 완료 보상과 구분. 재화·두루마리·승패 깃발·특별소환 창 회귀 검사는 처치 수입을 포함한 잔액으로 대조한다.

표시 크기는 이전의 1.6배다. Popup Scale 설정으로 코인·숫자·더하기 기호를 함께 조절한다.
