# 윷 결과 버튼·상점·Esc 메뉴 — 2026-11-19

> 2026-11-19 후속 배치: [윷 결과·던지기·소환·이동 배치](YutActionLayoutSpec.md)를 적용했다. 완성형 카드 원본과 새 크기/위치가 현재 기준이며 아래 이전 분리 이미지·크기 보존 설명보다 우선한다.

## 확정 동작

- 도·개·걸·윷·모 결과에 맞춰 소환 이름과 이동 1·2·3·4·5칸 이미지를 교체한다. 빽도는 소환 불가/뒤로 1칸 이미지다. 기존 버튼 크기·배경·누름 이미지·실제 행동 처리는 유지한다.
- 상점의 5개 상품 행은 목록 패널 중앙 기준 Y=320,160,0,-160,-320으로 정렬한다. 위아래 여백과 행 간격을 맞춘다.
- 구매 즉시 기존 Shop_Purchased_Stamp.png를 해당 행 위에 표시하고, 기존 구매 완료 텍스트 렌더러는 도장과 중복되지 않도록 숨긴다. 상품 상세는 계속 열어볼 수 있다. 도장 자체는 클릭을 막지 않는다.
- 구매 제한은 **10웨이브 스테이지 전체**에 걸쳐 유지한다. 상점 재개방·웨이브 전환·사용형 아이템 소비로 재입고되지 않는다. 기존 ShopPurchaseController의 구매 기록을 표시하므로 가격·재화·효과 처리와 저장 범위를 바꾸지 않는다. 새 게임/재도전의 새 씬에서는 초기화된다.
- 진행 화면의 상시 메인/종료 버튼 대신 **Esc → 일시정지 메뉴**를 제공한다. 메뉴에는 계속하기·메인 화면·게임 종료가 있다. 양피지·금색 테두리·붉은 버튼과 이순신 Bold 글꼴을 사용한다. 올림/누름은 같은 크기에서 색상 전환으로 표현한다.
- 준비/전투 중 Esc로 메뉴를 열면 진행을 멈추고 원래 열린 상점·인벤토리·특별소환·유닛 선택과 배속을 보존한다. 계속하기 또는 메뉴에서 Esc로 복귀한다. 처리 중인 이동·소환·구매·아이템/재화 알림이나 승패 확정 뒤에는 새 메뉴를 열지 않는다.
- 메인/종료는 기존 진행 소멸 확인창을 거친다. 메뉴에서 연 확인창을 취소하면 일시정지 메뉴로 돌아간다. 다시 계속하기를 선택할 때 저장한 배속을 복원한다. 기존 결과 깃발의 메인/재도전 기능은 유지한다.
- **Esc는 이동 선택 취소가 아니라 메뉴 호출**이다. 이동 선택을 취소하는 기존 우클릭은 유지한다. 이 변경은 YutActionSpec의 이전 작업07 설명보다 우선한다.

## 연결과 재현

- ThrowYut 씬의 TurnController에 YutActionButtonVisuals를 연결했다. 표시만 담당하며 윷 결과 소비나 이동 규칙을 소유하지 않는다.
- ShopCatalogUI.purchasedStamps에 5개 도장 Image를 연결했다. StageExitConfirmation은 메뉴와 기존 종료 확인창의 일시정지 소유권을 함께 관리한다.
- StageExit 루트 Canvas 정렬 순서 200과 GraphicRaycaster로 별도 상점 Canvas 위에서 표시·입력을 처리한다. 메뉴 배경은 전체 화면 입력을 막는다.
- Assets/Editor/UIRefinementSetup.cs의 Apply는 이 UI 연결을 재생성하는 편집 도구다. 이전 StageExitBuilder를 단독 재실행하면 구형 진입 UI를 만들 수 있으므로 이후 UIRefinementSetup.Apply도 실행한다. 플레이 중에는 실행하지 않는다.
- Unity 6000.3.28f1의 실제 ThrowYut Play Mode에서 검사했다. 새 UI 검사와 기존 구매·상점·나가기·우클릭 취소·준비 입력 검사 결과는 Docs/Verification에 기록했다. 화면 예시는 Docs/Previews/UIRefinement에 있다.

## 새 이미지

Assets/Art/PauseMenu/Panel.png와 Button.png는 기존 게임 UI를 참고해 생성한 빈 배경이다. 글씨는 Unity Text로 분리되어 있다. Patch Pixel 폰트는 사용하지 않았다. 기존 구매 완료 도장과 윷 버튼 아트는 재사용했다.
