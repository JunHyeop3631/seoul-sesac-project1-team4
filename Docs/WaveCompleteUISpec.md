# 웨이브 완료 두루마리와 완료 보상

## 적용 범위

- 전투 시작 시 뜨던 어두운 덮개와 시작 두루마리를 제거한다.
- 기존 `Wave`의 완료 판정, 적 소환, 사망 애니메이션 대기, 턴 진행은 유지한다.
- 중간 웨이브 완료 시 보상을 즉시 지급하고 다음 준비 단계로 넘어간 뒤 완료 알림을 재생한다.
- 마지막 웨이브는 등록된 `WaveManager.waves` 배열의 마지막 항목이다. 마지막 승리와 하트 0 패배에서는 기존 결과 패널을 사용한다.
- 알림은 재화 지급이나 단계 전환을 기다리게 하지 않으며, 입력과 시간이 멈추지 않는다.

## 재화

- 시작 일반재화는 기존 기획의 120(기본 윷 비용 20 × 6회)이다. `StageCurrency.startingBalance`에서 조정한다.
- 중간 웨이브의 완료 보상은 해당 `WaveData.completionReward`에 기록한다. 초기값은 60이며, 추가 완료 보상을 포함할 때는 이 값에 최종 지급 합계를 설정한다.
- `StageCurrency.Balance`가 실제 보유 재화이며 상단 `GoldNumberDisplay`는 이를 표시한다. 화면의 임시 숫자 9999는 잔액의 기준이 아니다.
- `TurnController`가 완료 시 지급한 실제 증가량과 완료한 웨이브 번호를 `WaveCleared` 이벤트로 전달한다. 다음 턴 번호나 UI의 고정 문자열로 보상/번호를 추측하지 않는다.
- 하트가 0이 된 웨이브와 최종 웨이브에는 중간 웨이브 완료 보상을 지급하지 않는다. 최종 보스 처치 보상은 별도 처치 보상 범위다.
- 이번 작업은 완료 보상 지급과 표시를 연결한다. 상점 구매, 윷 비용 차감, 적 처치 보상, 아이템에 따른 추가 보상 계산은 이번에 새로 구현하지 않는다.
- 재도전/씬 재진입 시 새 잔액으로 시작하며 파일 저장은 하지 않는다.

## 화면 및 애니메이션

- 승인된 꽃 없는 긴 두루마리와 진한 세로 구분선을 사용한다.
- 표시: `Wave {완료한 번호} 방어 성공 | 코인 +{실제 지급량}`.
- `Wave`와 코인은 이미지이며 숫자와 한글은 기존 이순신 Bold 폰트로 표시한다.
- 13개 동일 크기 프레임으로 0.4초 펼침 → 1.5초 유지 → 0.3초 사라짐. 글자는 펼침이 끝난 뒤 나타나며 늘어나지 않는다.
- UI 시간은 전투 배속과 관계없는 실제 시간이다.
- 모든 그래픽과 CanvasGroup의 클릭 차단을 해제한다. 재생 도중 윷 던지기, 소환, 이동 등의 준비 조작이 가능하다.
- 다음 전투 시작/승리/패배/컴포넌트 비활성화 시 남은 알림을 즉시 숨긴다.
- 프리팹의 위치, 크기와 애니메이션 시간은 Inspector에서 조정할 수 있다.

## 검증 항목

1. 전투 시작 시 시작 두루마리가 뜨지 않는다.
2. 중간 웨이브의 마지막 적 처리가 끝나면 보유 재화가 한 번 증가한다.
3. 두루마리의 번호는 완료한 웨이브, 금액은 실제 증가량과 일치한다.
4. 알림 중 다음 준비 단계의 윷 조작이 가능하다.
5. 마지막 웨이브 승리/패배는 완료 알림 없이 기존 패널을 표시한다.
6. 재도전 시 잔액을 초기화하고 보상이 중복 지급되지 않는다.
7. 등록 목록을 10개로 확장하면 9웨이브 완료 알림과 10웨이브 최종 승리가 자동 구분된다.

재생 검증은 검증용 복사본에서 Unity의 `-batchmode -executeMethod WaveCompleteVerification.Run`으로 실행한다. `Verification/WaveComplete/report.json`과 실제 씬 캡처를 출력한다. 검증은 재생 중에만 적 수/보상/현재 턴을 변경하며, 씬과 원본 WaveData 에셋은 저장하지 않는다. 런타임 검증에서는 보상을 73으로 바꾸어 실제 증가량 120→193과 표시를 대조한다. 게임의 저장된 보상 설정은 60이다.

프리팹 재생성 메뉴: `Tools > Yut UI > Rebuild Wave Complete Prefab`. 재생성하면 프리팹의 화면 위치와 시간 설정도 기본값으로 돌아간다.

이 문서는 이번 변경의 범위를 기록한다. 기존 TurnSpec/WaveSpec의 과거 구현 상태 설명과 충돌할 경우 이 문서의 완료 알림/완료 보상 항목을 적용한다.
