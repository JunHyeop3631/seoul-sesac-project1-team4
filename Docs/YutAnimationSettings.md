# 윷 스프라이트 애니메이션 설정

네 가지 조합은 제작 단계에서 고정한 서로 다른 3D 축으로 렌더링한다.
게임에서는 완성된 스프라이트 프레임을 재생한다.

좌표는 X=화면 오른쪽, Y=화면 위쪽, Z=카메라 쪽이다.
아래 회전축은 길이가 1인 정규화 벡터를 소수 여섯 자리로 표시했다.

| 시트 | 시작 → 착지 | 주회전축 (X, Y, Z) | 주회전 수 | 주회전 속도 | FPS | 전체 길이 |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| Yut_BackToBelly | 등 → 배 | (0.920506, 0.250138, 0.300165) | 2.5바퀴 | 1.898734바퀴/초 | 60 | 1.600000초 |
| Yut_BackToBack | 등 → 등 | (0.199800, 0.939061, 0.279720) | 3바퀴 | 1.974684바퀴/초 | 52 | 1.846154초 |
| Yut_BellyToBelly | 배 → 배 | (0.559860, -0.549863, 0.619845) | 3바퀴 | 2.126582바퀴/초 | 56 | 1.714286초 |
| Yut_BellyToBack | 배 → 등 | (0.589978, -0.509981, -0.625976) | 2.5바퀴 | 2.025316바퀴/초 | 64 | 1.500000초 |

주회전 속도는 공중 회전 구간(0~79번 프레임)의 값이다.
계산식은 `회전 수 × FPS / 79`이며, 전체 길이는 `96 / FPS`다.
시작과 착지 면이 다른 두 조합은 공중 구간의 마지막 25%에 추가 자세 보정을
부드럽게 적용해서 목표 면이 정면을 향하도록 한다. 위 속도는 이 추가 보정 회전을 제외한 주회전 값이다.

## 축 사이의 차이

축의 정방향과 역방향을 같은 축선으로 취급하여
`acos(abs(dot(axisA, axisB)))`로 계산했다.
가장 가까운 두 축도 **55.676187°** 차이가 난다.

| 축 조합 | 축선 각도 |
| --- | ---: |
| 등→배 / 등→등 | 59.816280° |
| 등→배 / 배→배 | 55.676187° |
| 등→배 / 배→등 | 76.843210° |
| 등→등 / 배→배 | 76.637500° |
| 등→등 / 배→등 | 57.579846° |
| 배→배 / 배→등 | 77.131401° |

## 공통 이미지 설정

- 96프레임, 12열 × 8행.
- 프레임 크기: 688 × 1344px. 전체 시트: 8256 × 10752px.
- 원본 윷 그림을 축소하지 않는다. 첫 프레임과 마지막 프레임에는 해당 원본 PNG를 그대로 넣는다.
- PPU: 100. 픽셀 크기에 맞는 동일한 원본 크기와 같은 월드 좌표 기준점을 유지한다.
- 모든 프레임은 고정 격자로 잘라 투명 여백 안의 상승·하강 이동을 보존한다.
- Custom Pivot: `(343.5 / 688, 327.5 / 1344)`.
- 상승 높이: 약 592.3551px. 높이 설정값을 697px에서 592.45px로 15% 낮췄다. 시작과 최종 착지 중심 Y는 1016.5px로 같다.
- 좌우 여백을 각각 24px 추가했다. 윷 자체를 확대·축소하지 않았다.
- 임포트 최대 크기: 16384. 압축 없음, Full Rect, Point 필터.

## 파일

이미지: `Assets/Art/Yut/Yut_BackToBelly.png`, `Yut_BackToBack.png`,
`Yut_BellyToBelly.png`, `Yut_BellyToBack.png`.

각 이미지와 같은 이름의 Unity 클립은 `Assets/Animations/Yut`에 있다.
클립의 프레임별 시간과 Sample Rate도 위 FPS에 맞춘다.

렌더러: [GenerateYutTumble.py](../Tools/GenerateYutTumble.py).
개별 제작값과 프레임별 검증 정보는 `Docs/Previews/<시트 이름>.json`에 저장한다.

## X 표시 버전

배면 원본만 `Yut_Belly.png`에서 `Yut_BellyX.png`로 교체한 별도 시트도 제공한다.
기본 이름 뒤에 `_X`를 붙여 기존 버전과 구분한다.

| 기본 시트 | X 표시 시트 | 시작 → 착지 |
| --- | --- | --- |
| Yut_BackToBelly | Yut_BackToBelly_X | 등 → X 배면 |
| Yut_BackToBack | Yut_BackToBack_X | 등 → 등. 공중에서 배면이 보일 때 X가 보인다. |
| Yut_BellyToBelly | Yut_BellyToBelly_X | X 배면 → X 배면 |
| Yut_BellyToBack | Yut_BellyToBack_X | X 배면 → 등 |

회전축, 회전 수, FPS, 점프 높이, 프레임 수와 격자, 원본 크기는 해당 기본 시트와 같다.
기존 버전은 유지하고 X 버전의 PNG와 같은 이름의 Unity 클립을 별도로 만든다.

재생성 예시: `python Tools/GenerateYutTumble.py --variant Yut_BackToBelly --belly-x`.
