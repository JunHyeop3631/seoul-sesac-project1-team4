작업33 갱신(2026-11-19): 실제 구매 버튼·일반재화 차감·보유/구매 이력·부족/구매 완료 표시와 품절 유지는 [구매 명세](ShopPurchaseSpec.md)에 연결했다. 아래 ‘구매 비활성/33 잔여’는 작업32 시점 기록이다. 실제 아이템 사용/효과는34~39에 남는다.

2026-11-19. 20장의 고정 판매5종과26장의 배경/최종 효과를 기준으로 기존 상점 UI의 선택 표시를 연결한다. 구매·보유·품절은33,인벤토리/실제 아이템 효과는34~39 범위다. 이 단계의 구매 버튼은 비활성으로 둔다.

26장 표의 원문 배경과 효과 문장을5개 [ShopItemDefinition](../Assets/Scripts/UI/ShopItemDefinition.cs) 에셋에 저장한다. 구미호의 자료/아이콘은 보존하지만 판매 목록에서는 숨기고 카탈로그에 등록하지 않는다. 기존 원본 이미지와 이름 시트는 그대로 사용한다.

[ShopCatalogUI](../Assets/Scripts/UI/ShopCatalogUI.cs)는 실제 상품 버튼을 누르면 선택한 에셋의 아이콘·이름 이미지·일반재화 가격·배경/효과 문구를 함께 갱신하고 선택 테두리를 표시한다. 최초에는 첫 상품을 선택하고 닫기/재열기에는 마지막 선택을 유지한다. 잔액 부족 여부로 상품 열람을 막지 않는다. 선택만으로는 결제·보유·아이템 효과를 실행하지 않는다. 준비에서만 선택할 수 있고 전투/일시정지/던지기/승패 등에는 실행을 거부한다.

[생성기](../Assets/Editor/ShopCatalogBuilder.cs)는 기존 행/아이콘 크기와 비율을 유지하면서 상품 에셋·가격 숫자·선택 테두리·설명 Text를 연결한다. 첫 상품이 상단 HUD에 가리지 않도록5개 행의 Y를280/440/600/760/920으로 배치한다. 긴 최종 문구가 들어가도록 설명판 높이와 본문 여백을 조정하며 기존 YiSunShin-Bold 글꼴을 사용한다. 상점 배경과 닫기 연결은 유지한다.

상점이 열리면 뒤쪽 윷/결과/상점/인벤토리/전투 시작5개 CanvasGroup의 원래 alpha/interactable/raycast를 저장해 숨기고,닫을 때 복원한다. 정보가 열린 상태에서 상점을 열면 정보 전환을 먼저 정리해 서로의 표시 상태가 겹치지 않게 한다. 기존 가격 Text/Image는 숨기고 GoldNumberDisplay의 숫자만 표시해100과최종가격의 중복을 제거한다.

개발/검증은 실제 ThrowYut 씬의 복사본에서 실행하며 fixture 선택/재화/상태를 씬에 저장하지 않는다. 전체 빌드·수동 완주는 이 작업의 검증 범위가 아니다.

## 검증

[ShopCatalogVerification](../Assets/Editor/ShopCatalogVerification.cs)에서 실제5개 상품 버튼의 포인터 클릭으로76개 검사 통과·검사 구간 런타임 오류0. [결과](Verification/ShopCatalogVerification.json).5종/가격/원문 배경·효과,아이콘·이름·양쪽 가격 동기화,선택 테두리1개,구미호 제외,설명 preferredHeight가 표시 영역 안에 들어감,행 크기/비율 유지,배경 조작 숨김/복원,잘못된 인덱스·닫힌 창·전투/정지/던지기/승패 거부를 확인했다.0원 열람·닫기/재열기 선택 유지·보유 윷 결과의 이후 정상 사용·다음 준비 선택 유지도 확인했다. 원문 문구 검증은 표시 데이터 검증이며 실제 아이템 효과 실행으로 간주하지 않는다.

첫 렌더링에서 기존 버튼이 설명/구매 영역을 덮고 정적 가격100이 새 숫자와 겹치는 것을 발견해 숨김/복원과 중복 가격 제거를 연결했다. 첫 상품의 HUD 겹침과 설명의 테두리 간섭도 조정 후 다시 검사·렌더링했다. 실제1920×1080 화면: [영혼의 결정](Previews/ShopProduct1.png)·[천운부](Previews/ShopProduct2.png)·[도깨비 복 주머니](Previews/ShopProduct3.png)·[도깨비 윷](Previews/ShopProduct4.png)·[천명전](Previews/ShopProduct5.png).

Game 뷰에서 상점을 열어5개 상품을 번갈아 누르면 아이콘/이름/가격/설명이 함께 바뀌고 선택 테두리가1개만 남아야 한다. 닫으면 윷 화면 버튼이 복원된다. 구매 실행은 다음 작업33에서 연결한다.

회귀 검증은 기존 준비 입력53개·정보 내용162개,합계215개 통과·각 검사 구간 오류0이다. [회귀 결과](Verification/ShopCatalogRegressionVerification.json). 변경 런타임/씬/생성기/검증 코드와 상품 에셋/메타16개 파일은 검증 복사본과 SHA-256 일치를 확인했고 변경 문서 링크 및 `git diff --check`를 통과했다.
