## 흐름에 따른 참조

1. [턴 흐름](TurnSpec.md)에서 준비·전투·종료 단계를 확인한다.
2. 준비 중 [윷 던지기](YutThrowSpec.md)로 결과를 얻는다.
3. [윷 행동](YutActionSpec.md)에서 결과를 소환 또는 이동에 사용한다. 이동 경로와 점유는 [윷판](YutBoardSpec.md)을 따른다.
4. 전투 시작 조건을 만족하면 [웨이브](WaveSpec.md)를 실행한다. [아군](AllySpec.md)은 자동으로 대상을 찾아 공격하고, [적군](EnemySpec.md)은 경로를 이동하며 피해를 받는다.
5. 웨이브 완료 후 [턴 흐름](TurnSpec.md)에 따라 턴을 종료하고 다음 준비 단계로 전환한다.

각 명세 상단에서 다른 명세와 해당 문서의 목차로 이동할 수 있다. 확정 규칙, 현재 구현, 미정·후속 범위는 각 문서의 해당 항목에서 확인한다.
