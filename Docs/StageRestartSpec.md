# 새 판 초기화와 재도전 — 작업40

> 2026-11-19 작업42: [실제Windows 빌드 메인 왕복](BuildMainEntrySpec.md)에서 게임 진입/메인 복귀 후 새 게임 초기화를 확인했다. 아래40의 승패 재도전171개는 에디터 검증이며 별도 근거로 유지한다.

일반 패배·보스 탈출 패배·최종 승리 뒤 실제 결과창의 다시 도전 버튼으로 게임 씬을 새로 로드해1웨이브/하트10/일반120/특별0/배속1을 시작한다. 메인 새 게임도 같은 초기 상태다. 일반/진화/백호 유닛·보드 점유·유닛/적/투사체 풀·현재 결과/선택·열린 패널·구매/보유·천운부/도깨비 윷/천명전 효과를 초기화한다.

기존 ResultFlagView의 결과 준비/중복 입력 잠금·0.08초 눌림 표시·씬 재로드를 재사용한다. 장면 수명의 상태/풀과 OnDestroy 정리를 통해 기존 인스턴스를 제거하고 새 인스턴스를 만든다. 별도 수동 초기화 목록이나 싱글톤을 도입하지 않는다. TitleScreenController.StartGame은 배속1 복원과1회 진입 잠금을 보완한다. 결과창 디자인/메인 구성/최종 빌드 진입은 후속41~46 범위다.

## 실행 흐름

1. [BattleStateHUD](../Assets/Scripts/UI/BattleStateHUD.cs)가 실제 승패 이벤트를 받아 도달 웨이브와 현재 씬 이름을 기존 ResultFlagView.Show에 전달한다. 결과 연출 중 버튼 입력을 막고 준비된 뒤 다시 도전을 허용한다.
2. [ResultFlagView.Retry→Navigate→LoadScene](../Assets/Scripts/UI/ResultFlagView.cs)는 IsVisible/ButtonsReady/navigating을 검사한다. 최초 클릭에서 잠그고0.08초 눌림 표시 뒤 Time.timeScale=1로 복원하고 현재 게임 씬을 단일 모드로 다시 로드한다. 동일/메인 버튼 재입력과 폐기된 결과 객체의 늦은 콜백은 새 판을 재로드하지 않는다. 기존 코드 경로를 재사용했다.
3. 씬 언로드가 이전 활성 유닛·UI·적·투사체를 제거하고 AllyPool/EnemyPool/ProjectilePool의 기존 OnDestroy가 풀과 소유 목록을 정리한다. 새 YutActionController의 점유/선택과 StageCurrency/StageInventory/ShopPurchaseController/아이템 효과/TurnController를 새 인스턴스로 초기화한다. 런타임 진행 데이터에 DontDestroyOnLoad나 정적 상태 저장을 사용하지 않는다.
4. [TitleScreenController.StartGame](../Assets/Scripts/UI/TitleScreenController.cs)에 startingGame과 활성 검사·배속1 복원을 추가했다. 최초 시작에서 잠그고 새 씬을 로드하므로 이전 메인 버튼 콜백이 다시 들어와도 두 번 로드하지 않는다.

## 검증

[실제 씬 Play Mode171개 검사 통과·검사 구간 오류0](Verification/StageRestartVerification.json). [검증 코드](../Assets/Editor/StageRestartVerification.cs).

- 실제 던지기,일반3기 소환/진화·일반 유닛 추가·백호 특별소환,비활성 진화 재료/투사체 풀,5종 구매,도깨비 윷/천명전 소비 예약,특별재화70,배속4,유닛/정보/상점/인벤토리 선택을 먼저 만들었다.
- 실제 일반 마지막 하트 누수 패배·보스 탈출 패배·보스 처치 승리 각각에서 결과창 실제 재도전 버튼의 포인터 콜백을 실행했다. 진입 연출 중 강제 콜백은 무실행이고 클릭 직후 재도전/메인 연타를 해도 씬 로드는1회다.
- 씬 로드 뒤 이전 씬의 전체 GameObject 스냅샷과 지갑/풀 참조가 모두 파괴됐음을 확인했다. 새 활성/비활성 아군·적·투사체와3종 풀/모든 보드 점유는 비어 있다.
- 1웨이브/하트10/일반120/특별0/배속1·미구매5종·보유0·할인/대기/활성 효과 없음·기본 비용20/보상 배율1을 확인했다. 이전 결과·선택·처리 잠금·정보/상점/인벤토리/특별소환/결과/완료 배너도 초기화된다. 관련 HUD도 새 상태와 일치한다.
- 재도전 뒤 실제 첫 던지기가120→100을 결제하고 정상 실행된다. 폐기된 결과창의 늦은 콜백은 다시 로드하거나 새 결과창을 열지 않는다.
- 실제 Title 씬에서 메뉴를 열고 배속4를 지정한 뒤 게임 시작 버튼을 눌러 같은 초기 상태/1회 로드를 확인했다. 이전 메인 버튼의 늦은 콜백도 무실행이다.

일부 웨이브 인덱스/일반 적 편성·하트·기존 결과 해제·빠른 탈출 경로는 메모리 fixture다. 각 실제 승패/단일 씬 재로드/씬 생성·파괴 경로를 실행한 검사이며1~10 전체 수동 완주나 플레이어의 OS 마우스 입력 검사는 아니다. 메인 시작과 결과 버튼의 실제 Unity Button 포인터 콜백을 호출했다. 테스트 재화/유닛/아이템/웨이브는 저장하지 않았다.
