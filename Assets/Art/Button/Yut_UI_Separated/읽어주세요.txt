윷 UI 분리 이미지
01_Icons: 소환 주머니 / 이동 화살표
02_Titles: 소환 / 이동 (하단 고정 문구에도 같은 이미지를 작게 사용)
03_UnitNames: 돼지 도사, 개 전사, 양 창병, 소 철퇴병, 말 궁수, 소환 불가
04_MoveSteps: 1칸, 2칸, 3칸, 4칸, 5칸, 1칸 뒤로
05_ButtonBases: 내용 없는 기본/눌림 버튼. 금색 구분선 포함.
06_Throw: 기본/눌림 윷 던지기 버튼. 숫자와 엽전 모두 제거, 비용 칸은 빈 상태.

모든 PNG는 투명 배경입니다.
분리 요소를 버튼 바탕 위에 각각 올려서 사용하세요.
백도는 소환 불가 문구만 표시하세요.
기본/눌림 버튼 바탕은 같은 크기입니다.
기존 참고 이미지의 스타일을 바탕으로 배경을 제거·재구성한 이미지라 원본 픽셀과 미세한 차이가 있습니다.
게임이나 데모는 수정하지 않았습니다.

제작: 내장 이미지 편집 도구
편집 요청: 아이콘·제목·유닛 이름·이동 칸 수를 투명 배경에 분리하고 원본 크림색 글자/갈색 외곽선 유지.
빈 버튼은 금색 프레임·자주색 바탕·구분선을 유지하고 글자와 아이콘 제거.
윷 던지기 버튼은 숫자와 엽전을 제거하고 빈 비용 칸 유지.
